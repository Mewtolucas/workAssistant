## For Windows Users

### Installation
```
1. Download the project as a ZIP file
2. Extract it to your desired location
3. Open the folder
4. Double-click: install-windows.bat
5. Follow the prompts
   - It checks Node.js
   - Installs everything
   - Asks for API key (optional)
   - Starts the app
6. Done! App is running ✨
```

### Starting the App Later
```
Just double-click: start-app-windows.bat
```

## Getting Your Claude API Key (Optional but Recommended)

### Why?
- Enables the **Summarizer** feature
- Enables **Flashcard generation**
- Without it: only Notes work

### How?
1. Go to: https://console.anthropic.com/
2. Sign in (or create free account)
3. Click **"API Keys"** in left menu
4. Click **"Create Key"**
5. Copy the key starting with `sk-ant-`
6. Paste it when the installer asks

Takes **2 minutes**!

## First Time Using the App?

### Dashboard
- See overview of all your data
- Quick stats on notes, flashcards, etc.

### Create a Note
1. Click **Notes** tab
2. Type a title
3. Type content
4. Click **"Save"**
✅ Note is saved locally!

### Summarize Text
1. Click **Summarizer** tab
2. Paste any text
3. Click **"Summarize"**
4. Claude generates a summary
✅ Copy and use it!

### Generate Flashcards
1. Click **Flashcards** tab
2. Give your set a title
3. Paste study material
4. Click **"Generate"**
5. Claude creates 10 Q&A cards
✅ Start studying!

### Use PDFs
1. Click **Notes**, **Summarizer**, or **Flashcards**
2. Click the green **"PDF"** or **"Upload PDF"** button
3. Select a PDF from your computer
4. Text is extracted automatically
✅ Use it in your workflow!

## Install Chrome Extension (Optional)

Lets you extract PDFs directly from your browser!

### For Windows
1. Open the `extension` folder
2. Double-click: `install-windows.bat`
3. Follow the prompts
✅ Extension is installed!

### For Mac/Linux
1. Open the `extension` folder
2. Double-click: `install-mac-linux.sh`
3. Follow the prompts
✅ Extension is installed!

### Using the Extension
1. Open any PDF in Chrome
2. Click the Personal Assistant icon (top right)
3. Click **"Extract PDF & Send"**
✅ PDF text is ready to use!

## Need Help?

### I see error messages during install
- **Make sure Node.js is installed** first
- Download from: https://nodejs.org/ (LTS version)
- Then run the installer again

### My API key isn't working
- Double-check you copied it correctly
- Make sure it starts with `sk-ant-`
- Go to console.anthropic.com to verify

### App won't start
- Delete `node_modules` folder
- Run the installer again
- Or check DOWNLOAD_AND_INSTALL.md for help

### Where are my notes saved?
- **Windows:** `C:\Users\YourName\.personal-assistant\notes\`
- **Mac:** `/Users/YourName/.personal-assistant/notes/`
- **Linux:** `/home/username/.personal-assistant/notes/`

They're saved as JSON files - easy to backup!
